# Embedded Folia Monet lyric rail

This local build uses MonetLyricsRail, MonetRailLine, timed tokens and their imported helpers from [Folia](https://github.com/chthollyphile/folia-major/tree/619cd7955bfb19a3813ef5d572d8fff839551628), licensed AGPL-3.0. The package includes the upstream license and credits. The corresponding host and glue sources are the Notch Harbor repository, including `scripts/folia-rail.tsx`, `scripts/build-folia-rail.mjs`, `scripts/build-local.sh`, and `NotchHomeView.swift`. The bundler applies the SwiftUI viewport's contrast, focus and line-gap overrides in memory; the vendored upstream sources stay intact. Keep the applicable GPLv3 and AGPLv3 obligations when conveying a combined build.

Provide the pinned Folia checkout through `BORING_FOLIA_SOURCE` and the package directory containing esbuild 0.25.12, React and React DOM 19.2.8, framer-motion 12.43.0, and @chenglou/pretext 0.0.9 through `BORING_FOLIA_DEPENDENCIES`. The signed application embeds a local HTML resource with network access blocked by Content Security Policy. SwiftUI passes the playback clock and matching timed lyrics, and clicks seek the existing player. The source timestamps are LRC line times, so intra-line progress is estimated. NetEase playback prefers matching LRC from NetEase before LRCLIB. Without timestamps the music page shows a status, not the full lyrics or artificial timing; builds without Folia use the native renderer for timed lines.
