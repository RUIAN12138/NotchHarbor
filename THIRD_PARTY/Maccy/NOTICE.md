## Referenced and adapted conventions

Production files:
`boringNotch/components/Clipboard/ClipboardHistoryStore.swift` and
`boringNotch/components/Clipboard/ClipboardHistoryArchive.swift`

- Ignored pasteboard markers: `org.nspasteboard.ConcealedType`,
  `org.nspasteboard.TransientType` and `org.nspasteboard.AutoGeneratedType`
  are checked on the full pasteboard type set and on each pasteboard item
  before any data is read.
- Change detection: a `changeCount` comparison gates every poll, and a
  before/after `changeCount` check rejects a snapshot that changed while it
  was being read.
- Multiple files: file groups are written back as one `NSPasteboardItem` per
  URL through `writeObjects`, preserving item order instead of copying path
  text.

## Deliberately not reused

- The Maccy application, menus, settings UI, history storage and app
  lifecycle.
- SwiftData/CoreData persistence and Maccy's `HistoryItem` model.
- `Sauce`, keyboard-layout handling, `CGEvent` paste injection and
  Accessibility permission requests. This feature never pastes for the user.
- App/source filtering, regex ignore rules, the paste stack, updater and
  notifications.
- Any third-party dependency of Maccy.

## Differences from upstream

- History keeps the 50-entry / 64 MiB total budget (16 MiB per image), now
  persisted locally in the app sandbox at
  `Application Support/ClipboardHistory`: a versioned metadata index plus
  content-addressed text/PNG/thumbnail assets. Nothing is uploaded, synced or
  shared over the network; the files stay on this Mac.
- File groups store security-scoped bookmarks and display names only. Source
  file contents are never copied into the history directory, and deleting a
  history entry never deletes the source file.
- Images are normalized to PNG in the background; TIFF/JPEG/HEIC are decoded
  with ImageIO and re-encoded before entering the store.
- The store is injectable with a private `NSPasteboard`; tests compile the
  production sources and use `scripts/test-clipboard.py` plus
  `scripts/test-clipboard-persistence.py`. No real `.general` pasteboard is
  read.

Packaging: `scripts/build-local.sh` copies this NOTICE and the upstream
LICENSE to `boringNotch.app/Contents/Resources/ThirdParty/Maccy/`.
